# iTimer 功能清单

当前版本 **1.9.0**（build 15）· 更新于 2026-10-10

这份清单列出 iTimer 现在有的功能，一行一个，写明它做什么、从哪个版本开始有。改动功能的提交要同时更新这里，规则见 [AGENTS.md](../AGENTS.md)。每个版本具体改了什么见 [CHANGELOG](../CHANGELOG.md)，面向用户的完整用法见 [README](../README.md)。

- 「版本」列是这个功能第一次发布的版本。之后行为有较大变化的，在说明末尾用括号注明，例如「（1.5.0 起按计时段拆分）」。
- 已经做完、还没发版的功能，版本列写「未发布」，发版时换成版本号。
- 去掉的功能不要直接删掉，移到文末的「已移除」。

## 1. 计时与注意力模型

代码：`Sources/ITimerCore/Store.swift`、`RecordTimes.swift`、`Analyzer.swift`、`FocusScore.swift`、`Streaks.swift`

| 功能 | 说明 | 版本 |
|---|---|---|
| 多任务并行计时 | 多个任务可以同时计时，每个都能开始、暂停、继续、完成、改名、删除 | 1.0 |
| 修改已完成记录的时间 | 在「今日完成」或分析页的「记录」中修改每段计时的开始、结束日期和时间；保留暂停间隔，完成日期随最后一段结束时间更新，统计和日历同步更新；不允许时间倒置、同一任务的计时段重叠或未来时间 | 1.9.0 |
| 脑裂线 | 同时计时的任务数达到它就算脑裂，默认 3，可在 2–8 之间调（设置或分析页工具栏） | 1.0 |
| 上下文切换 | 已有任务在计时时又开一个新线程，记一次切换 | 1.0 |
| 只做这个 | 一键暂停其他所有线程，只留这一个计时 | 1.3.2 |
| 专注度（0–100） | 单核时间全额计入，并行计 55%，脑裂计 15%，再按每小时切换次数扣分（最多 15 分）；85+ 心流、65+ 稳定、40+ 分散，其余为过载 | 1.3.2 |
| 连续天数 🔥 | 每天单核计时满 25 分钟，连续天数 +1 | 1.0 |
