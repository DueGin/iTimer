# iTimer

> 给大脑的活动监视器 —— 一个会数你同时开了几个线程的计时器。

普通计时器默认你一次只做一件事。现实不是：写方案时回消息，回消息时看群，看群时想起还有个 bug。iTimer 不假装你是单线程的，它诚实地记录**同一时刻有几件事在计时**，并把这份碎片化程度变成看得见的数字。

「脑裂（split-brain）」本是分布式系统的术语：集群里的节点各自为政、互相打架。你的注意力也一样。

## 定位

| | |
|---|---|
| **给谁** | 同时推进多条线的知识工作者：独立开发者、运营、创业者、PM |
| **解决什么** | 「今天好忙但好像什么都没做完」——忙的是切换，不是产出 |
| **不做什么** | 不做团队协作、不做计费工时、不做自动监控。一切由你手动开始、手动收尾，数据只在本机 |
| **一句话** | 记录时间，也记录注意力碎成了几瓣 |

## 核心概念

- **线程**：一个正在计时的任务。
- **脑裂线**：同时计时的任务数达到它就算脑裂（默认 3，可在 2–8 之间调）。
- **上下文切换**：已有任务在跑时又开一个新线程，记一次。
- **单核**：只有一个任务在计时的时间，也是连续天数（🔥）的依据：每天单核满 25 分钟 +1。
- **专注度（0–100）**：单核时间全额计入，并行计 55%，脑裂计 15%，再按每小时切换次数扣分（最多 15 分）。
  - 85+ 心流 · 65+ 稳定 · 40+ 分散 · 其余 过载
- **任务集合**：由你自己新建的一组任务（例如「本周交付」「副业」），带颜色。在日程表单的「集合」一行点「+ 新集合」就地新建并归入，右键菜单「集合 › 新建集合…」也能到那里；改名、换色、排序和删除在设置里。一个任务只归入一个集合。删除集合后，其中的任务仍在，只是不再归集。不会自动生成集合。
- **子任务**：一个任务下面可以挂一层子任务，用来拆步骤。点任务行上的「添加子任务」按钮（或右键 › 子任务 › 添加子任务…），父任务下方会出现输入框，回车添加一条，可以连续添加，Esc 结束；新子任务先放在「时间待定」，想做时点开始即可。也可以右键一个已有任务 › 子任务 › 归入其他任务。子任务跟着父任务的集合走，不能再往下嵌套。父任务行显示完成进度（如 `1/3`），按集合显示时子任务缩进排在父任务下面；点进度胶囊（或右键 › 折叠子任务）可以把子任务收起来，折叠状态会记住，收起时如果有子任务在计时，胶囊旁会亮一个小圆点，添加子任务时会自动展开。删除父任务会一并删除它的子任务。
- **标签**：每个任务可以打多个自由标签，不需要预先创建。
- **备注与进展**：每个任务有一条常驻备注（结论、约束、下次接着做什么），以及按时间追加的进展评论。做着做着随手记一句，比事后回忆准。

## 界面

**菜单栏**：一个会裂开的大脑图标。一个任务时显示计时，多个任务时显示 `12:34 ×2`，到脑裂线就变红并显示「脑裂 3」。

越过脑裂线的那一刻，图标会**炸开**：先鼓胀、发抖、蓄力，然后一道闪光，两半脑子飞开并翻转，碎片四散，最后弹回裂开的形状。线程开得越多，爆炸越猛。只要一直处于脑裂，每隔几秒会有一次小余震（发抖加火星）。面板打开时动画会停住，关上后再继续，所以在面板里开第三个任务，关上面板的瞬间它就会炸。系统开了「减弱动态效果」时不播放。

**弹出面板**
- 主卡片：最久的那个线程的大号计时；右上角是「线程槽」，一格一个线程，槽位数就是脑裂线，最后一格描了粉边，一眼看出还剩几个名额。
- 今日色带：从今天第一次计时到现在的负载条，青色专注、橙色并行、粉色脑裂。
- 每个任务一行：左侧圆钮暂停或继续，◎「只做这个」一键暂停其他所有线程，✓ 完成，添加子任务，双击标题改名，删除要连点两下。右键有完整菜单；菜单开着时计时数字会暂停，关掉后跳回正确的时间。
- 今日完成：做完的事不会消失，可以一键「再来一段」。
- 输入框的占位文字会随负载变化：「再开一个就到脑裂线了…」，开新线程前先提醒你一下。
- 最近做过的事以胶囊形式列出，点一下直接开始，输入时会自动过滤。
- 输入框支持 `写周报 #汇报 #PPT`：`#` 打标签。输入 `#` 时下方会出现已有标签的补全。
- 列表可在「按集合」和「按状态」之间切换。按集合时每个集合是一个文件夹：点文件夹折叠或展开，双击名字改名，右上角的文件夹按钮新建集合；把任务拖到文件夹上即可归入，没归入的任务在「未归集」里。右键文件夹可以在里面新建日程或删除集合（任务保留）。
- 任务行显示 `#标签`（按状态排列时还显示集合胶囊）；右键菜单里的「集合」「子任务」「标签」可以直接归入集合、添加子任务或切换标签。
- 任务行的气泡按钮打开「备注和进展」：备注随时改，进展按时间追加，记过的任务会亮起气泡。
- 日程表单：日期一行直接列出「待定 / 今天 / 明天 / 后天 / 下周一」，其他日期点右侧日历按钮选；表单里还有集合和标签两行，点选即可，集合一行末尾可以直接新建。

**主窗口**
- 专注度圆环、结论和五个关键数字（活跃、单核、脑裂占比、上下文切换、峰值线程），每项都和上一周期对比：今天对昨天同一时段，7 天对前 7 天，30 天对前 30 天。箭头颜色按「好坏」而不是「涨跌」来定，例如切换次数变多显示为粉色。悬停数字可以看到它的定义。
- 洞察卡片：用大白话说出值得注意的事，例如「15 点最容易脑裂」「每小时切换 4.0 次」「最长单核 1 小时 10 分」
- 今天：线程泳道（每个任务一条泳道，脑裂时段用粉色底色标出）和负载曲线
- 7 天、30 天、全部：专注度趋势（每天一个分数，没计时的日子会断开）和按天构成
- 时段分布、各级时长、集合和标签环形图、常一起做的事、记录（超过 8 条时折叠）
- 工具栏的「集合」筛选：只看某个集合（或未归集）的任务，所有图表、洞察和导出的 CSV 都跟着过滤
- 所有图表都能悬停：泳道和负载曲线会显示时间游标，并列出那一刻有哪些任务在跑；柱状图会高亮悬停的那一根，其他变淡，同时弹出明细；悬停标签图例会高亮对应的扇区

**交互**：所有自定义按钮共用一套 hover 反馈：悬停时浮出带色背景，部分按钮会轻微放大，图标变成对应颜色，按下时会压缩一下。任务行、记录行、「常一起做的事」的每一行悬停时背景会变亮。最近任务的胶囊按钮悬停时会显示 ▶。

**提醒**：进入脑裂时发通知，建议用「只做这个」收拢线程；单个任务连续计时 3 小时会提醒你是不是忘了暂停。两种提醒都能在设置里关掉。

**设置（⌘,）**：脑裂线、任务集合（新建、改名、换色、排序、删除）、提醒开关、日历同步、登录时启动、打开数据文件所在位置。

## 设计原则

1. **诚实而不说教**：文案带点自嘲（「左右脑互搏」「脑子裂成 3 瓣」），只陈述发生了什么，不评判你。
2. **颜色即语义**：青色、橙色、粉色只表示专注、并行、脑裂；标签配色刻意避开这三种颜色。
3. **在开新线程前介入**：线程槽、输入框提示、脑裂通知，都在你「再开一个」之前轻轻拦一下。
4. **一键收拢**：发现脑裂后，恢复只需要一下点击（◎ 只做这个）。

## 构建

```bash
./scripts/build-app.sh release   # 输出 dist/iTimer.app
swift test                       # 核心逻辑测试
```
